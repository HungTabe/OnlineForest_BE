Setup DB at SMSS
CREATE DATABASE ForestOnlineDb;

Create migration for code first method
- dotnet build
- dotnet ef migrations add InitialCreate
- dotnet ef migrations remove (if delete migration)
- dotnet ef database update

Update User Role from USER to ADMIN
UPDATE [ForestOnlineDb].[dbo].[Users]
SET [Role] = 'ADMIN'
WHERE [UserId] = 1;  -- Thay 1 bằng UserId thực tế của người dùng cần thay đổi
